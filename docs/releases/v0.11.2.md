PairDesk 0.11.2 makes connecting from another network work with nothing to set up.

### New in 0.11.2

- **The PairDesk relay is live.** When your phone can't reach the computer directly (a different Wi-Fi, mobile data, a computer behind someone else's router), the two now meet at the PairDesk relay automatically. No Tailscale, no router settings, nothing to type. The relay only passes bytes along: the connection is still encrypted from the phone to the computer and pinned to the computer's own certificate, so the relay can't read or change it.
- **Reach a computer through your own router.** On the phone, ⋮ → **Add an address** now accepts a name (such as a dynamic-DNS name) as well as an IP address, with an optional `:port` for a router that forwards a different outside port. **Remote access** on the computer explains the three steps and shows its address and port. This needs a router that can forward a port; a provider that shares one address between customers makes it useless.
- Names typed in by the owner are accepted; names that arrive in a pairing link are still limited to IP addresses and `.ts.net`, because a link can come from someone else.
- Internal: a single `tools/check.sh` now runs the same checks as CI, and a file-transfer test no longer fails on a busy machine.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
- Update both the computer and the phone. A PairDesk already running on the computer is stopped and replaced by the setup. Paired phones stay paired.
