PairDesk 0.11.3 stops the phone giving up on a connection that is still fine. If you saw "The computer stopped answering" while using the phone, this is the release for you. Update the phone; the computer is unchanged.

### Fixed in 0.11.3

- **The phone waits longer before giving up.** It used to call the computer dead after 10 seconds without a reply. That is too short for mobile data, a weak Wi-Fi signal, or a connection through the relay. It now waits 25 seconds.
- **A sleeping phone is not a silent computer.** When Android freezes the app (screen off, another app in front) its timers stop, and on waking it used to conclude at once that the computer had gone quiet. It now notices that it was frozen and gives the computer a fresh chance to answer.
- **It reconnects by itself.** If the link really does break, the phone tries again on its own, up to three times in a row, and stays on the control screen showing "Reconnecting…" instead of sending you back to the list. It only shows an error when it can't get back. Closing the connection yourself never reconnects.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
- A PairDesk already running on the computer is stopped and replaced by the setup. Paired phones stay paired.
