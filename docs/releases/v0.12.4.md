PairDesk 0.12.4 fixes the screen view sometimes turning into a shredded, blocky picture that stayed until you changed the quality. Update the computer; the phone app is unchanged.

### Fixed in 0.12.4

- **A broken screen picture now clears by itself.** The screen view is video, and a phone that missed or mis-decoded one frame kept showing a broken picture until the computer sent a fresh full picture, which only happened at the start or when you changed the quality. While the screen changes, the computer now sends a fresh full picture every 3 seconds, so a glitch is gone within moments.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
