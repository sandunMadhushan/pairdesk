PairDesk 0.8.0 is the first release meant for everyone: proper installers, automatic updates, and a new icon.

### New

- **Windows setup.** Installs PairDesk for you, with no administrator rights needed. It adds a Start menu entry and an entry in Settings → Apps, and uninstalls cleanly.
- **Linux packages.** `.deb` for Ubuntu, Debian and Mint; `.rpm` for Fedora and openSUSE; an AppImage for any distribution.
- **Automatic updates on the computer.** PairDesk checks GitHub once a day and shows *Install update* on its settings page. Every update is signed, and PairDesk checks the signature and checksum before installing anything. You can turn the daily check off. The `.deb`/`.rpm` copies link to the download instead, because the package manager installs those.
- **The phone app tells you about new versions** (the copy from GitHub). F-Droid copies get their updates from F-Droid.
- **New icon** for the app, the computer program and the installers.
- **Website and privacy policy:** [pairdesk.madhushan.me](https://pairdesk.madhushan.me).

### Fixed

- After updating, the old copy no longer deletes the new copy's settings address on its way out.

### Before you install

- **The Android app is now signed with PairDesk's permanent release key.** Earlier test builds used a temporary key, so Android won't install 0.8.0 over them. Uninstall the old app first, then install this one and scan the pairing code again; remove the old phone from the computer's PairDesk page. This happens only once.
- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
- Running an older PairDesk on the computer? Just run the new setup. It stops the old copy and replaces it.
