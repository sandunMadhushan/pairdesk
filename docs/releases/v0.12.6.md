PairDesk 0.12.6 makes ending a connection harder to do by accident and simplifies "connect from anywhere": the app now talks only about the PairDesk relay. Update both the computer and the phone.

### New in 0.12.6

- **The ✕ asks before it disconnects.** In the phone's control screen, the ✕ at the top left (and the back gesture) now ask "End the connection?". In the Screen tab it looked like it closed just the picture, but it ended the whole connection.

### Changed in 0.12.6

- **No more Tailscale in the app.** The Tailscale card, install links and wording are gone from the computer's Remote access page and from the phone. Away from home, PairDesk uses the relay (or your own router). A computer already paired through a Tailscale address still connects to it.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
