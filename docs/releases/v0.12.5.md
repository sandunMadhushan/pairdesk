PairDesk 0.12.5 makes connecting through your relay steadier: the computer notices a dead relay link and reconnects by itself, the relay can use TLS on port 443, and you can use more than one relay. Update both the computer and the phone.

### New in 0.12.5

- **Connection details and a "Check now" button.** In the computer's settings, each relay shows whether it answers and whether this computer is registered with it. The phone's "Can't reach" sheet has a matching "Check the relay" button.
- **TLS on the relay port.** A relay started with `--tls-cert` and `--tls-key` accepts TLS and plain connections on the same port (443). The computer and the phone try TLS first for relay names and fall back to plain, so older relays keep working.
- **Several relays.** The computer can connect to up to four relays at once, and the phone tries all of them.

### Fixed in 0.12.5

- **A dead relay link is noticed and replaced.** After sleep, a network change or a silent drop, the computer now reconnects within seconds instead of waiting on a connection that no longer works, and a long outage no longer leaves it retrying slowly.
- **The relay allows 512 connections per address** instead of 64, so several phones or computers behind one home or campus connection are no longer refused.
- **Windows:** the sign-in screen's phone server now gets the relay token too, so the relay also works before anyone signs in.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
- **Relay owners:** to use the new limit and TLS, update and restart the relay. TLS also needs a certificate for the relay's name; see `docs/RELAY.md`.
