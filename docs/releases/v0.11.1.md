PairDesk 0.11.1 fixes connecting to a computer from another network. If your phone works on Wi-Fi but not through Tailscale, this is the release you want. Update both the computer and the phone.

### Fixed in 0.11.1

- **The phone keeps up with the computer's addresses.** Until now a phone only knew the addresses it was handed when it paired or last connected, so a computer that got Tailscale afterwards stayed unreachable from anywhere else, however long you waited. The computer now tells every connected phone as soon as its addresses change: turn Tailscale on while the phone is connected over Wi-Fi and the phone has the route a moment later, with nothing to re-pair. The same goes for a new Wi-Fi address and for the relay coming up.
- **Pairing links carry every route.** A scanned or tapped link now includes the computer's Tailscale address *and* its Tailscale name (`something.ts.net`), not only its home-network addresses. Scanning a fresh code is enough to teach a phone the way home.
- **Windows Firewall no longer blocks Tailscale.** Windows asks which networks an app may be reached on and leaves "public" ones out, and it files the Tailscale adapter as public — so phones got through on Wi-Fi and never through Tailscale, with no error to explain it. **Remote access** on the computer now has **Allow PairDesk on all networks**, which writes firewall rules for every kind of network (Windows asks for administrator rights once), and says when the rules are missing. The Microsoft Store package ships with those rules already.
- **Add an address yourself.** On the phone, the ⋮ menu next to a computer has **Add an address**, for typing the `100.x.x.x` address or `.ts.net` name shown on the computer's **Remote access** page. A pairing made before you set up Tailscale is no longer a dead end.

### Also new: the phone updates itself

- The app already noticed new releases; now it installs them. **Update** on the notice downloads the APK from the GitHub release, checks it against the SHA-256 in the signed manifest, and hands it to Android, which asks you to confirm and replaces this copy. No browser, no finding the file in Downloads. Android asks once for permission to let PairDesk install apps; the card takes you to that setting.
- **Settings → About → Check for updates** asks GitHub straight away, instead of waiting for the once-a-day check.
- A download that doesn't match the signed hash or the expected size is deleted and never installed, and Android itself only accepts an APK signed with the same key as the copy you have. F-Droid builds leave updating to F-Droid, as before.

### If you were stuck

After updating both: on the computer open **Remote access** and press **Allow PairDesk on all networks**. With Tailscale signed in on both devices the phone should connect from any network. If it still doesn't, use ⋮ → **Add an address** on the phone with the address that page shows.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
- A PairDesk already running on the computer is stopped and replaced by the setup. Paired phones stay paired.
