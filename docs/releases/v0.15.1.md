PairDesk 0.15.1 lets the phone control windows that run with more rights than PairDesk, such as the Windows Security PIN box.

### Fixed in 0.15.1

- **The pointer froze on the "Windows Security" PIN prompt** (for example when Edge asks for your PIN before showing passwords), on apps run as administrator, and on Task Manager. Windows silently drops input from a normal program to those windows. PairDesk now sends input through its helper while one of them is in front, so the pointer moves and the PIN can be typed from the phone. This needs *Sign-in screen and admin prompts* turned on in PairDesk's settings on the computer.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
