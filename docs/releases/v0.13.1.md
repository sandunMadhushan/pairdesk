PairDesk 0.13.1 is a small update for Windows: the program now carries its own C runtime, so it never needs the Visual C++ Redistributable (the Microsoft Store asked for this). Everything from 0.13.0 is included: **direct connections**, where the screen goes straight from your computer to your phone whenever the networks allow it.

### Changed in 0.13.1

- **Windows:** no Visual C++ runtime needed by the program or the Store package.

### New in 0.13.0

- **Direct connections.** Away from home, the PairDesk relay introduces your phone to your computer and they open a direct path through both routers when the networks allow it; otherwise the relay carries the connection. The phone's title bar says **Direct** or **Relay**.
- **Router port, automatically** (UPnP or NAT-PMP), and **IPv6**: the phone can connect with no relay at all when either works.
- **Relay: STUN** over UDP. If you run your own relay, open UDP 443 and 47900 too.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
