PairDesk 0.12.3 brings the lock screen and sign-in screen to the Microsoft Store version of the computer app, and lets it check for updates in the Store. Update the computer; the phone app is unchanged.

### New in 0.12.3

- **Unlock your computer from your phone, in the Microsoft Store version too.** The Store package now comes with the PairDesk helper, which Windows starts with the computer. Turn on **Sign-in screen and admin prompts** in PairDesk's settings (no administrator prompt) and your phone can use the lock screen, the sign-in screen and administrator prompts. It needs Windows 10 version 2004 or newer.
- **Check for updates in the Microsoft Store.** The Updates card in the Store version has a button that opens the Store's updates page.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
