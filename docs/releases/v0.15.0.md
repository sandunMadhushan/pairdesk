PairDesk 0.15.0 fixes typing into the Windows sign-in PIN box and adds Wake-on-LAN.

### New in 0.15.0

- **Typing a Windows PIN from the phone.** On the sign-in screen, lock screen and admin prompts, text is now typed as real key presses. The PIN box ignored the way PairDesk typed before. Anything the keyboard layout can't type still goes in as before.
- **Wake a sleeping computer (Wake-on-LAN).** *Wake it up* is in each computer's menu and on the "Can't reach" sheet. The phone sends the wake signal itself (same network) and also asks your other paired computers to send it on their network, so an always-on PC or Raspberry Pi at home can wake another one while you are away. Connect to each computer once while it is awake so the phone learns its network address.

### Good to know

- The computer needs Wake-on-LAN turned on in its BIOS and network card settings, and usually a cable connection. Wi-Fi laptops rarely wake this way.
- Typing a PIN on the sign-in screen has been tested only in the build and with automatic tests so far, not on every Windows PC. Tell us if it fails on yours.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
