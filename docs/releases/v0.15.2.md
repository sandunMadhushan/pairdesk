PairDesk 0.15.2 fixes the pointer and keyboard on the Windows Security PIN and password box.

### Fixed in 0.15.2

- **The Windows Security PIN box** (for example when Edge asks for your PIN before showing saved passwords) now accepts the phone's pointer and typing. 0.15.1 sent input there through the helper, but the helper refuses the normal desktop on purpose; it now makes one narrow exception for Windows' own credential prompt. Other administrator windows are still not controlled through the helper, so a program running as you can't use it to drive them. This needs *Sign-in screen and admin prompts* turned on in PairDesk's settings.
- PairDesk's log now records when input goes through the helper and which program's window was in front, to make problems like this easy to trace.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
