PairDesk 0.9.0 makes the screen view much smoother, and lets you use the Windows lock screen, sign-in screen and administrator prompts from your phone. It also includes everything from 0.8.0 (installers, automatic updates, the new icon), which wasn't published separately.

### New in 0.9.0

- **Smoother screen view.** The computer now sends real video (H.264) instead of a stream of pictures. Scrolling, dragging windows and playing videos look much smoother, and it uses less data. Phones that can't show the video get pictures as before, automatically. If the screen view misbehaves, turn off *Settings → Smooth screen view* in the phone app.
- **Windows: lock screen, sign-in screen and administrator prompts.** Windows shows these on a protected screen that normal programs can't control, so until now the phone couldn't use them. On the computer, open PairDesk and turn on **Sign-in screen and admin prompts**; Windows asks for administrator permission once. After that, your phone can:
  - unlock the computer (type your PIN or password),
  - answer administrator (UAC) prompts,
  - use the sign-in screen after a restart, before anyone signs in.

  It works through a small helper service. Turn it off on the same page, or by uninstalling PairDesk.

### From 0.8.0

- **Windows setup.** Installs without administrator rights, with a Start menu entry and an entry in Settings → Apps.
- **Linux packages.** `.deb`, `.rpm` and AppImage.
- **Automatic updates.** The computer checks once a day and offers *Install update*. Updates are signed and checked before anything is installed. The phone app (GitHub copy) tells you when a new version is out.
- **New icon**, website and privacy policy at [pairdesk.madhushan.me](https://pairdesk.madhushan.me).

### Before you install

- **Phone:** if you have 0.7 or older, uninstall it first. Earlier test builds used a temporary signing key, so Android won't install over them. Then install this version and scan the pairing code again; remove the old phone on the computer's PairDesk page. This happens only once.
- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
- A PairDesk already running on the computer is stopped and replaced by the setup.
