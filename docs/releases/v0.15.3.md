PairDesk 0.15.3 keeps the Windows sign-in screen helper up to date.

### Fixed in 0.15.3

- **The sign-in screen helper now updates with PairDesk.** The helper runs from its own protected copy in Program Files, which a normal update didn't replace. After updating to 0.15.1 or 0.15.2 it could keep running an older release, so fixes for the sign-in screen and the Windows Security PIN box didn't take effect until *Sign-in screen and admin prompts* was turned off and on again. PairDesk now notices an older helper and reinstalls it once after an update (Windows asks for administrator permission). If you decline, the *Sign-in screen* page offers *Update the helper*.
- The helper now reports which release it runs, and PairDesk's log says when it updates the helper.

If you're coming from 0.15.1 or 0.15.2 and the PIN box still doesn't accept the phone, turn *Sign-in screen and admin prompts* off and on once; later updates won't need this.

### Before you install

- **Windows:** the setup isn't code-signed yet. If SmartScreen warns, choose *More info → Run anyway*. Check downloads against `SHA256SUMS.txt`.
