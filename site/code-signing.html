Code signing policy

PairDesk has applied for free code signing from the SignPath Foundation, with signing by SignPath.io. Until then, Windows downloads are not signed. Check them against SHA256SUMS.txt on the release page.

Signed files are built only by GitHub Actions from this project's public source code (github.com/sandunMadhushan/pairdesk), and each release is approved by hand before it is signed.

Team roles

  • Committers and reviewers: Sandun Madhushan
  • Approvers: Sandun Madhushan

Changes from outside contributors are reviewed by a committer before they are merged.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it, apart from a daily check for new versions on GitHub, which can be turned off in PairDesk's settings. See the privacy policy.
